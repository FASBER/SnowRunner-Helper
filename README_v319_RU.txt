SnowRunner Helper v0.31.9 — исправление Validate после v0.31.8

Причина: тест OTA v0.31.8 требовал запись ota_setup_status_v0.31.8.txt,
но Inno Setup содержал жёстко прописанную v0.31.7.

Исправление:
- setup_snowrunner.iss: имя файла отчёта и версия в его тексте
  теперь формируются через {#MyAppVersion}; менеджер обновляет эту
  переменную при каждом релизе. Повторная ошибка исключается.
- tests/test_ota_first_launch_v316.py: проверяет использование
  динамической версии и отсутствие устаревшего захардкоженного номера.
- Версионные тесты и метаданные обновлены до 0.31.9.
- Исправления трёх функций из v0.31.7 сохранены.

Инструкция:
1. Выбери этот ZIP в SnowRunner Update Manager v0.1.6.
2. В поле «Новая версия» укажи 0.31.9, текущая в GitHub — 0.31.8.
3. Проверь обновление, загрузи исходники в GitHub.
4. Подожди зелёного Validate. Только потом выпускай релиз.

Обычные профили и игровые сохранения этим пакетом не изменяются.
