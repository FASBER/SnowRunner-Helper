SNOWRUNNER HELPER v0.31.11 — СОГЛАСОВАННЫЙ ИНТЕРФЕЙС

Этот ZIP — ГОТОВОЕ обновление для SnowRunner Update Manager v0.1.6.
Папка клона, генератор ZIP, PatchKit и отдельные BAT-файлы для пользователя НЕ требуются.

ЭТАЛОН: последнее подтверждённое изображение пользователя от 20.11.2026
(1672×941: горный заголовок, профиль, левая навигация, две колонки).

ИЗМЕНЕНИЯ
1. Шапка и навигация максимально приближены к утверждённому изображению.
2. Строка профиля: баланс, опыт и задания берутся только из реально
   прочитанного сохранения, неизвестные показатели показываются как «—».
3. Каталог грузов: компактные 8 строк слева; полная карточка справа.
4. Поиск, сортировка, категории, фильтры карт и регионов по имеющимся
   рецептам, прокрутка, выбор груза и открытие рецепта остаются реальными.
5. Переход к «Крафт», «Калькулятор», «Настройки», страницы «Главная» и «Гараж»
   используют только выбранный профиль.
6. Кнопка «Обновить» и редактирование иконки груза сохранены.
7. Сохранены веса из v0.31.10 (MapRunner — справочник, а не данные сохранения).
8. Не изменены игровые сохранения, OTA безопасность, пользовательские
   черновики, механика тем и AppId установщика Windows.

ОГРАНИЧЕНИЯ
- Точное пиксельное совпадение не подтверждено на Windows пользователя.
- Имя игрока, уровень, процент прохождения, связанные с грузом задания и
  текущая карта не подменяются сведениями из картинки-эталона.
- Полный Windows CI и запуск настоящего приложения на Windows проверяются
  после загрузки в GitHub. QA-скриншот выполнен в Tk-тестовом окружении.

ПОРЯДОК УСТАНОВКИ
1. В SnowRunner Update Manager v0.1.6 выбери ЭТОТ архив.
2. Проверь текущую версию 0.31.10 и новую версию 0.31.11.
3. Выгрузи код, проверь зелёный Validate на GitHub Actions.
4. Только затем выпусти релиз Windows.
5. Проверь OTA и сделай реальный скриншот для сравнения с эталоном.

GitHub автоматически не изменяется при скачивании ZIP.
