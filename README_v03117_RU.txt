SnowRunner Helper v0.31.17 — исправление GitHub Actions

Назначение: восстановить автоматическую проверку исходников после неуспешного
запуска Validate SnowRunner Helper #17 для коммита 9312435 (v0.31.16).

Исправлено:
1. Семь старых тестов ожидают устаревшую 0.31.15; проверка теперь динамически
   сопоставляет VERSION.txt, version.json, update_config.py и имя установщика.
2. tests/test_upgrade_v316.py использовал pytest, не установленный GitHub Actions.
   Все десять тестов переведены на стандартный unittest.TestCase и unittest.mock.
   Теперь CI с `python -m unittest discover -s tests -p 'test_*.py' -v`
   автоматически обнаруживает эти десять тестов, не требуя менять workflow.
3. Добавлена запись о CI-исправлении в локальный сворачиваемый Changelog.

Что НЕ менялось: дизайн UI «Экспедиция», рисунки, крафт, игровые сохранения,
пользовательские профили, логика OTA-подписей и подтверждений.

Проверка на Linux: 10 новых unittest-тестов пройдены, compileall пройден.
Полная повторная проверка GitHub Actions и сборка Windows EXE НЕ проводились:
это возможно только после публикации через SnowRunner Update Manager.

ВНИМАНИЕ:
- в Update Manager выбрать новую версию 0.31.17 (строго выше 0.31.16);
- сначала загрузить исходники, дождаться успешной GitHub Actions проверки;
- выпускать GitHub Release и включать OTA только после зелёного CI.
