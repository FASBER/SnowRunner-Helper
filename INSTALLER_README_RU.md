# SnowRunner Helper — сборка установщика v27

## Что реализовано

- Нативный установщик Windows через **Inno Setup 6**.
- На шаге выбора папки доступно поле полного пути и кнопка «Обзор…».
- Приложение по умолчанию устанавливается в `%LOCALAPPDATA%\Programs\SnowRunner Helper`, без прав администратора.
- При обновлении предлагается ранее выбранный каталог (`UsePreviousAppDir=yes`, постоянный `AppId`).
- Создаётся ярлык меню «Пуск»; ярлык рабочего стола — по выбору пользователя.
- Включено удаление приложения через стандартный Windows-деинсталлятор.
- Персональные данные: `%USERPROFILE%\SnowRunnerCraftAssistant` — **вне** папки программы, при удалении не затрагиваются.

## Как получить настоящий Setup.exe

1. На Windows 10/11 установите Python 3.10+ и [Inno Setup 6](https://jrsoftware.org/isinfo.php).
2. Распакуйте архив с исходным проектом в любую папку.
3. Запустите **`build_installer_windows.bat`** двойным щелчком.
4. После успешной сборки файл будет в `installer_build\SnowRunnerHelper_Setup_v27.exe`.
5. В мастере установки выберите папку вручную или через «Обзор…»; разрешён любой доступный диск с правом записи.

При первой сборке Python должен иметь доступ к интернету для установки PyInstaller, Pillow, fonttools и cryptography. В ходе сборки сначала запускаются автоматические тесты проекта.

## Обязательная проверка на Windows перед передачей другим пользователям

- Установить в нестандартную папку (например, `D:\Apps\SnowRunner Helper`).
- Запустить приложение через меню «Пуск», затем через ярлык рабочего стола.
- Сохранить тестовый профиль и план, закрыть приложение.
- Запустить тот же установщик поверх текущей установки: ранее заданный путь должен предлагаться автоматически, профиль должен сохраниться.
- Удалить приложение через «Приложения» Windows и проверить, что персональный профиль остался на месте.
- Переустановить в другую папку и проверить, что сохранённые данные снова доступны.

## Статус

Файлы сценария установки и сборки подготовлены. **Настоящий Setup.exe не собран и не протестирован в текущей Linux-среде**, потому что отсутствуют компилятор Inno Setup, Wine и Windows-библиотеки. Одобрённый дизайн окна — референс; стандартный мастер Inno Setup не выглядит в точности как этот макет. Два BMP в `installer_assets` задают брендинг приветственного окна/шапки.

## OTA-обновления (v27)

Модуль безопасных OTA-обновлений добавлен, **но до публикации официального URL и ключа он отключён**. После сборки приложения необходимо настроить `update_config.py` с адресом HTTPS-манифеста и публичным ключом Ed25519, затем повторно собрать EXE и установщик. Раздача обновлений предполагает публикацию подписанного `manifest.json` и готового `Setup.exe` на HTTPS-сервере.

Приложение предлагает установку только по выбору пользователя, скачивает в `%USERPROFILE%\SnowRunnerCraftAssistant\updates`, проверяет размеры и SHA-256 из подписанного манифеста, сохраняет черновики перед запуском нового установщика и не трогает сохранения игры. При обновлении Inno Setup предлагает прежнюю папку (`UsePreviousAppDir=yes`).

Инструкция для владельца ключей: `release_tools/README_RU.md`. **Приватный ключ в архив НЕ включать.** Проверка на настоящем Windows с подписанными релизами всё ещё необходима.
