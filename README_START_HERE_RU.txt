SNOWRUNNER HELPER — OTA FIX v0.31.6
===================================

Назначение: уменьшить риск однократной ошибки "Failed to load Python DLL"
сразу после OTA-установки, когда установщик предлагает слишком ранний запуск
PyInstaller one-file EXE. Причина конкретной DLL-ошибки не доказана; исправление
убирает автоматический запуск только из OTA-установщика и добавляет диагностику.

КАК ПРИМЕНИТЬ
1. На компьютере должна быть рабочая v0.31.5.
2. Распаковывать ZIP не нужно: открой SnowRunner Update Manager v0.1.6.
3. Выбери этот архив и нажми «Проверить обновление».
4. Проверь версию 0.31.6, список изменений; загрузи код в GitHub.
5. После успешных CI-тестов выпусти тег v0.31.6 через менеджер.
6. На установленной v0.31.5: «Настройки» → «Проверить обновления».
7. Установи v0.31.6 через OTA. После завершения установщика ЗАПУСТИ программу
   ВРУЧНУЮ с ярлыка. Для OTA автозапуск намеренно отключён.
8. Проверь версию 0.31.6, темы/черновики и повторный запуск.

ОТЛИЧИЯ
- Новый установщик v0.31.6 узнаёт OTA от старой v0.31.5 по папке
  %USERPROFILE%\SnowRunnerCraftAssistant\updates (старый клиент не умеет /OTA=1).
- Новые OTA-запуски добавляют маркер /OTA=1.
- При успешном OTA-установлении создаётся текстовый файл:
  %USERPROFILE%\SnowRunnerCraftAssistant\updates\ota_setup_status_v0.31.6.txt
- Если не удаётся стартовать отложенный установщик, смотри старый журнал:
  %USERPROFILE%\SnowRunnerCraftAssistant\updates\ota_launch_error.txt
- Обычная ручная установка сохраняет пункт «Запустить приложение».
- AppId, папка профилей, подпись Ed25519 и проверка SHA-256 сохранены.

ПРОВЕРЕНО ЛОКАЛЬНО: Python-тесты. Windows-сборку Inno Setup и полноценное OTA
нужно подтвердить отдельно. Это патч исходников, а не готовый EXE.

НЕ ЗАГРУЖАЙ секреты/PEM, игровые архивы и пользовательские сохранения.
