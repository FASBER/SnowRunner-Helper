# SnowRunner Helper v27 — OTA обновления

## Добавлено

- При запуске приложения — фоновая проверка обновлений, если есть HTTPS endpoint и проверенный Ed25519 public key. По умолчанию **ОТКЛЮЧЕНО** до настройки серверной публикации.
- В настройках — окно «Обновления приложения», версия и настройка проверки при запуске.
- Проверка подписанного JSON-манифеста Ed25519 (безопасный закрытый ключ НЕ включён).
- Только HTTPS, ограничение размеров, SHA-256 контроль скачанного Setup.exe, очистка частичных загрузок и отмена скачивания.
- Окно согласия с новой версией и подтверждения установки, кнопки «Позже», «Пропустить версию».
- Сохранение черновика до запуска настоящего Inno Setup установщика; локальная папка и пользовательские профили остаются прежними.
- Инструменты подготовки подписанных релизов в `release_tools/` (не запускать приватный ключ на непроверенном ПК).

## Для настоящей OTA-доставки

1. На безопасном офлайновом ПК создать приватный ключ; хранить его вне архива и Git.
2. Добавить публичный ключ и HTTPS URL постоянного манифеста в `update_config.py`.
3. Собрать настоящий Windows Setup.exe на Windows (`build_installer_windows.bat`).
4. Выгрузить Setup.exe и подписать `manifest.json`, ссылающийся на тот же файл.
5. Опубликовать `manifest.json` на HTTPS-сервере; только после этого приложения обнаружат следующий релиз.
6. Проверить реальное обновление Windows, включая сохранённую папку установки, данные профилей и отсутствие SmartScreen предупреждений при наличии Authenticode сертификата.

**Ограничение:** подписанный манифест сам по себе не создаёт сервер обновлений и не заменяет цифровую подпись Authenticode. Текущий комплект не содержит работающего публичного сервера обновлений, реального скомпилированного Setup.exe и приватного ключа. Это готовые исходные модули и сценарий сборки.
