SNOWRUNNER HELPER 0.31.13 — ПЛАВНАЯ И БЫСТРАЯ ПРОКРУТКА

Готовый ZIP для SnowRunner Update Manager v0.1.6. Дополнительные
установщики, генераторы ZIP и клонирование GitHub не требуются.

УСТРАНЕНА ЗАДЕРЖКА ПРОКРУТКИ МЫШЬЮ:
- Вместо полной перерисовки Canvas на каждое событие колеса
  накопленные движения объединяются в один кадр (12 мс).
- Движение на несколько делений не теряется: применяется общая сумма.
- Кнопки, нажатие на полосу прокрутки и Ctrl+колесо остаются без задержки.
- У редактора внешнего вида колесо работает над полями и кнопками,
  ускоренная прокрутка только в колонке параметров, предпросмотр не двигается.
- Старый классический интерфейс не изменялся.
- Обработчики мыши повторно привязываются к Tk после установки
  динамических перехватчиков утверждённого интерфейса.

НЕ МЕНЯЛИСЬ: дизайн, игровой профиль, файлы SnowRunner, крафт,
веса, OTA-подписи, установочный AppId и настройки пользователя.

ПРОВЕРКА:
- 15 новых тестов логики: пройдены.
- 10 тестов компоновки предыдущей версии: пройдены.
- Tk Canvas: пять быстрых событий колеса объединены в одну отрисовку,
  список сдвинулся на ожидаемые десять строк.
- Настоящий Windows EXE и полный GitHub Actions Validate проверяются
  после загрузки исходников через менеджер.

ДЕЙСТВИЯ:
1. В Update Manager выбери этот готовый ZIP.
2. Укажи переход 0.31.12 -> 0.31.13.
3. Загрузи код в GitHub.
4. Дождись зелёного Validate; только тогда выпускай релиз.
5. Проверь колесо над каталогом, крафтом, калькулятором и в редакторе.

GitHub не меняется от скачивания архива.
