SnowRunner Helper v0.31.14 — выбор и сохранение игрового профиля

УСТАНОВКА
Готовый ZIP для SnowRunner Update Manager v0.1.6. Выберите архив,
укажите версию 0.31.14 (предыдущая: 0.31.13), проверьте,
загрузите в GitHub и дождитесь зелёной проверки Validate.
Только после успешной проверки выпускайте релиз.

ЧТО ИЗМЕНЕНО
1. В окне «Подключение SnowRunner и профили» появился доступный
   список «Мой локальный» и обнаруженных слотов Steam (1, 2, 3).
2. Кнопка «СОХРАНИТЬ ВЫБРАННЫЙ ПРОФИЛЬ» видна сразу под списком.
3. Пока нажата только строка — активный профиль НЕ переключается.
4. Сохранение проходит через существующую защиту черновиков и
   записывает selected_game_profile в настройки; после рестарта
   профиль сохраняется. При ошибке чтения прогресса профиль остаётся
   выбранным, ошибка показана отдельно.
5. Панель диагностики перенесена ниже кнопок. Не меняется дизайн
   других экранов, игровые сохранения никогда не записываются.

ЛОКАЛЬНАЯ ПРОВЕРКА
9 тестов нового диалога, видимость 12 кнопок в окне 960x665;
реальный тест Tkinter, скриншоты выбора и сохранения.
Полная проверка Windows EXE и GitHub Actions ещё требуется.

ТЕХНИЧЕСКИ
Новый модуль profile_selector_v314.py устанавливает новую версию
диалога в класс Application через существующий theme_v317.py.
Остальные файлы пользовательских данных и профилей не затронуты.
