SNOWRUNNER CRAFT ASSISTANT — v18
================================
Дата: 2026-11-19
Платформа: Windows (исходники проекта, Python + Tk/Pillow)

ЧТО ГОТОВО
- Профильное хранение грузов, черновиков, истории загрузки, ручных маршрутов и пользовательских сопоставлений.
- Чтение распознаваемых игровых JSON-сохранений в режиме только чтения с 12-секундным опросом выбранного профиля.
- Сводка завершённых задач, посещённых уровней, статусов гаражей и автомобилей на хранении.
- Предварительный просмотр cargoAvailable с ручным сопоставлением внутренних игровых ID.
- Предпросмотр дефицита груза на одном выбранном складе без автоматических списаний.
- Редактирование порядка остановок и связь ручного маршрута с загрузкой.
- Диагностика структуры JSON без приватных значений.

ПРОВЕРКА
- 73 автоматических теста: успешно.
- 6 графических smoke-сценариев в Linux/Xvfb: успешно.
- Исходные игровые сохранения в синтетических тестах не изменялись.

ЧТО ЕЩЁ ТРЕБУЕТСЯ
- Реальные сохранения конкретной версии игры для достоверной схемы гаражей, складов и карт.
- Реальные данные дорог/координат для автоматического построения маршрутов.
- Сборка и тест на Windows (EXE не включён; build_windows.bat запускается на Windows).
- Проверка Steam/Epic, конфликта облачных сохранений и реального горячего клавишного оверлея.

НА WINDOWS
1. Распакуйте архив полностью.
2. Установите Python 3.10+ с Tkinter.
3. Запустите run_windows.bat.
4. Для сборки исполняемого EXE запустите build_windows.bat.
5. В настройках выберите папки игры/сохранений и нужный профиль.

Неофициальная программа; не изменяет файлы сохранений SnowRunner.
