# SnowRunner Helper — переименование v0.30.0

Публичное имя, название окон, имя EXE и нового установщика: **SnowRunner Helper**.

Для обновления существующих установок **сохранён прежний AppId** `SnowRunnerCraftAssistant.CommunityEdition` в Inno Setup. Не изменять его в последующих версиях.

**Сохранена прежняя папка пользовательских данных** `%USERPROFILE%\SnowRunnerCraftAssistant` (`Path.home() / APP_NAME` в `core.py`): так уже созданные профили, маршруты, пользовательские рецепты и настройки остаются доступными без миграции. Не удалять и не переименовывать её.

Для новых установок каталог по умолчанию: `%LOCALAPPDATA%\Programs\SnowRunner Helper`; обновления сохраняют предыдущий путь благодаря `UsePreviousAppDir=yes`. Старый EXE и старые ярлыки удаляются только внутри установщика через `[InstallDelete]`, данные профилей не трогаются.

Имя будущих GitHub Releases assets: `SnowRunnerHelper_Setup_v0.30.0.exe`, `update.json`. OTA downloader и launcher должны использовать идентичные имена. GitHub репозиторий и публичный ключ Ed25519 пока не настроены.

Старые файлы `RELEASE_NOTES_v*.txt` и исторические скриншоты могут содержать предыдущий бренд, поскольку документируют прежние версии.
