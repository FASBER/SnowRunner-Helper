# SnowRunner Helper v0.31.6 — первый запуск после OTA

**Наблюдение:** после OTA до v0.31.5 на одном компьютере ошибка загрузки
`python311.dll` показалась только один раз. Следующий обычный запуск успешен.
Это не доказывает конкретную причину ошибки.

**Изменение:** Inno Setup не предлагает автоматический запуск после установки,
если setup запущен из `SnowRunnerCraftAssistant\updates` (совместимость с OTA
клиента v0.31.5) или с параметром `/OTA=1` (новые клиенты).
После закрытия мастера пользователь запускает новую версию с ярлыка.
Для обычной ручной установки вариант запуска после установки оставлен.

**Диагностика:** успешная OTA-установка создаёт
`%USERPROFILE%\SnowRunnerCraftAssistant\updates\ota_setup_status_v0.31.6.txt`.
Ошибка подготовительного OTA-запуска фиксируется прежним
`ota_launch_error.txt`.

Сохранены AppId, UserPreviousAppDir, папка профилей, контроль подписи OTA.
Более глубокую диагностику случайной ошибки DLL можно добавить после
получения повторяемого сценария на реальной Windows.

> Важно: новая версия установщика уже учитывает старый клиент v0.31.5,
> который не передаёт параметр `/OTA=1`. GitHub не изменён этим ZIP.
