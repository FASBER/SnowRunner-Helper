SnowRunner Helper 0.31.5 — исправление проверки Windows в GitHub Actions

Этот пакет предназначен для SnowRunner Update Manager v0.1.6.
Он включает исправление OTA, подготовленное ранее для 0.31.4, и исправление
кроссплатформенного теста, который блокировал Windows-сборку 0.31.4.

ИСТОЧНИК СБОЯ
В tests/test_ota_deferred_v314.py сравнивались слеши разных видов:
C:/Windows/WindowsPowerShell/powershell.exe и C:\Windows\WindowsPowerShell\powershell.exe.
В версии 0.31.5 перед сравнением путь нормализуется. Рабочий механизм OTA не ослаблен.

ВАЖНО
Тег v0.31.4 уже был отправлен на GitHub, но его сборка закончилась ошибкой.
Не передвигайте старый тег и не создавайте релиз на основе его ошибочного коммита.
Используйте новый тег v0.31.5 после успешных тестов в ветке main.
Пока не выполнены реальные испытания, не считайте автоматическую установку OTA проверенной.

РЕКОМЕНДОВАННАЯ ПРОВЕРКА
1. В менеджере выберите этот ZIP и проверьте переход версии 0.31.4 -> 0.31.5
   в ИСХОДНИКАХ (на компьютере может оставаться установленная 0.31.3).
2. Проверьте список файлов, загрузите код в main и дождитесь зелёного Validate.
3. Запустите выпуск v0.31.5 новым тегом, НЕ переписывая тег v0.31.4.
4. После сборки установите v0.31.5 вручную, если старая OTA-установка снова
   заблокирует обновляемые файлы. Полный тест нового механизма: v0.31.5 -> v0.31.6.
5. Профили должны сохраниться в %%USERPROFILE%%\SnowRunnerCraftAssistant.

Изменения в текущем архиве ограничены 14 исходными файлами и не затрагивают игровые сохранения.
