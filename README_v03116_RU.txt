SnowRunner Helper v0.31.16 — ИСХОДНОЕ ОБНОВЛЕНИЕ ДЛЯ SNOWRUNNER UPDATE MANAGER
Дата: 21.11.2026
Разработчик: FASBER

ВНИМАНИЕ: это техническая сборка исправлений, а не подтверждённый полный
финальный релиз по всем требованиям. Готовый Windows EXE в этой среде НЕ
собирался, и реальная проверка на Windows + SnowRunner необходима.

УСТАНОВКА
1. Открой SnowRunner Update Manager v0.1.6.
2. Укажи этот ZIP исходников. Архив содержит файлы, обновляющие
   соответствующие файлы репозитория FASBER/SnowRunner-Helper; менеджер
   применит их поверх исходников существующего репозитория.
3. Проверь список изменённых файлов и версию v0.31.16.
4. Публикацию на GitHub и OTA-обновление выполняй только после проверки
   и твоего отдельного одобрения. В этой сборке ничего не опубликовано.

ИЗМЕНЕНИЯ
- Более ровные рамки в UI «Экспедиция»; сохранена панорама игры.
- Убрана белая артефактная полоса над иконкой «Грузы», шесть иконок
  бокового меню центрированы внутри своих кнопок без искажения пропорций.
- Перестроенные настройки и выровненные поля каталога грузов.
- Сортировка: имя, слоты, подтверждённый вес и категория.
- Более ровное боковое меню и верхняя статистика; цвет подсветки
  сворачивания, разворачивания и закрытия при наведении.
- Анимированное скроллирование основных списков и редактора оформления.
- Название профиля: Steam PersonaName только при подтверждённом совпадении
  из локального Steam loginusers.vdf, или пользовательский псевдоним.
- В гараже появились две вкладки: «Моя техника» и «Каталог техники».
  Техника читается из локального сохранения и initial.pak (если выбран).
- Окно «О приложении» с разработчиком FASBER и детальным сворачиваемым
  Changelog, локальным списком изменений и показом один раз после обновления.
- Улучшен захват Ctrl/Shift/Alt/Win в редакторе глобальной горячей клавиши.
- Включён файл проверки реального размера и прозрачности иконок.

ОГРАНИЧЕНИЯ (НЕ СКРЫВАТЬ)
- Нет полной официальной коллекции лицензированных реальных 4K фотографий
  грузовиков, прицепов, полуприцепов, модулей и всех грузов/рецептов.
  Случайные или созданные изображения не подставляются. Старые иконки
  сохраняются. Функция image_quality_audit_v316.py позволяет проверить их.
- Каталог техники зависит от initial.pak установленной SnowRunner; без
  файла игры не заявляется полная база DLC или совместимости.
- Прицепы на картах не выдаются за собственность игрока, если сохранение
  не содержит надёжной записи владения.
- Нельзя гарантировать работу сочетания поверх эксклюзивного полноэкранного
  режима или когда другую программу/Windows занимает сочетание клавиш.
- Движение колеса в редакторе внешнего вида и основных списках улучшено,
  но абсолютно все сторонние диалоги ещё не унифицированы.
- Проверка на реальной Windows-машине и тесты полного приложения без
  оригинального набора исходников пока не выполнены.

ДАННЫЕ ПОЛЬЗОВАТЕЛЯ
Не изменяй и не удаляй каталог %USERPROFILE%\\SnowRunnerCraftAssistant,
находящийся вне папки установщика. Обновление работает только с исходниками
приложения, игровые сохранения читаются без модификации.
Приватные игровые сохранения, Steam IDs, пароли и ключи OTA в ZIP не входят.

ОФОРМЛЕНИЕ И ФОТО
В отдельной папке «Фото» представлены тестовые снимки новых компонентов
на реальной Tk Canvas оболочке и окна Changelog. Это НЕ доказательство
собранного и запущенного финального Windows EXE.
