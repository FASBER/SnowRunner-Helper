SNOWRUNNER HELPER v0.31.10 — ВЕС ГРУЗОВ

ПРОБЛЕМА: в v0.31.9 все массы отображались как «Нет данных», поскольку
catalog.json не содержит полей массы. Это был лишь корректный fallback,
не рабочий справочник веса. Исправлено.

НОВОЕ:
- 68 из 73 позиций каталога имеют значение массы УПАКОВАННОГО груза
  из справочника MapRunner (https://www.maprunner.info/cargo),
  проверено 20.11.2026 по таблице Packed weight.
- 3 позиции с переменной массой показывают ДИАПАЗОН, а не выдуманную среднюю.
- 5 позиций без однозначных данных показывают «Нет данных».
- Значения относятся к справочнику MapRunner, НЕ к локальным игровым файлам.
- Если позже появится подтверждённая масса из игровых файлов, она приоритетнее.
- Игровые файлы, настройки, сохранения и черновики НЕ затрагиваются.

ПРИМЕРЫ:
  Металлические балки — 5 т; Рулоны металла — 1 т;
  Деревянные доски — 0,5 т; Буёк — 2,341 т;
  Средние брёвна — 5–8,3 т;
  Ремонтные очки, вода, варианты досок и особые запчасти — нет данных.

ЭТО ГОТОВЫЙ ZIP ДЛЯ SNOWRUNNER UPDATE MANAGER v0.1.6.
Не нужен PatchKit, clone, BAT-генераторы и ручное слияние кода.
Выбрать ZIP, в поле «Новая версия» поставить 0.31.10,
«Проверить обновление» -> «Загрузить код в GitHub» -> дождаться Validate.
Релиз выпускать только после зелёной Validate и успешной сборки.

ПРИМЕЧАНИЕ: модифицируется только модуль справочного веса и версионные файлы.
Полный Windows EXE на этой машине не собран. Проверка на ПК пользователя
должна подтвердить, что подписи в строках каталога видны без обрезания.
