# SnowRunner Helper v0.31.4 — исправление OTA-установки

**Статус: исходный ZIP-патч для утверждения и проверки на Windows, не EXE и не опубликованный релиз.**

## Какую ошибку исправляем

Во время OTA-перехода v0.31.2 → v0.31.3 встроенный установщик Inno Setup сообщил, что не может автоматически закрыть использующие обновляемые файлы приложения. При ручной установке v0.31.3 запустилась и сохранила пользовательские данные.

В v0.31.3 `update_launcher.launch_installer()` запускал установщик, пока процесс Python/PyInstaller ещё оставался запущен, и лишь затем `UpdaterUI._install()` вызывал `root.destroy()`. Это могло блокировать замену SnowRunnerHelper.exe.

## Исправление

- После проверки Ed25519 и SHA-256 основным OTA-механизмом создаётся отдельный системный процесс Windows PowerShell.
- Он ждёт завершения текущего процесса SnowRunner Helper **и, если приложение собрано в PyInstaller one-file, его родительского загрузчика** (общий предел ожидания 2 минуты), не убивая остальные процессы.
- Затем он **ещё раз** проверяет размер и SHA-256 установщика и запускает подписанный релизный EXE через `Start-Process`.
- При неудаче запуска или повторной проверке записывает ошибку в `%USERPROFILE%\SnowRunnerCraftAssistant\updates\ota_launch_error.txt`.
- Папка пользователя, AppId установщика, пользовательские профили и сохранения не изменяются.
- `update_launcher.py` не получает секреты, не хранит приватный OTA-ключ и не использует shell=True.

## Установка патча через SnowRunner Update Manager

1. Сохраните резервную копию `%USERPROFILE%\SnowRunnerCraftAssistant`.
2. Откройте **SnowRunner Update Manager** и выберите ZIP этого патча.
3. Нажмите «Проверить обновление» и убедитесь, что версия переходит **0.31.3 → 0.31.4**.
4. После согласования загружайте код в GitHub. Проверьте зелёную проверку GitHub Actions.
5. Только затем выпускайте релиз v0.31.4.
6. **Сначала установите v0.31.4 вручную**: старая установленная v0.31.3 всё ещё содержит ошибочный OTA-установщик.
7. Полноценную проверку исправленного механизма выполняйте при следующем выпуске: **v0.31.4 → v0.31.5** (на отдельной/резервной установке Windows). **Не откатывайте версию поверх новой без резервной копии.**

## Проверки

В ZIP включён новый тест `tests/test_ota_deferred_v314.py`. Он проверяет ожидание завершения PID, повторное хеширование и защиту от подмены пути. Тесты реального Windows PowerShell/замены заблокированного EXE необходимо выполнить на Windows после сборки.

**Примечание:** это исправление процесса OTA, видимый дизайн окна обновлений остаётся прежним.
