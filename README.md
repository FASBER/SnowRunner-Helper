## Историческая документация предыдущих версий

# SnowRunner Helper — версия v18 (Windows)

Неофициальный автономный помощник по грузам и крафту SnowRunner. Включает редактор оформления, калькулятор, справочник и мини-окно поверх игры.

## v18 — черновики, склады, ручные маршруты и диагностика

Версия v18 развивает v17 и сохраняет прежние функции. В меню **Настройки → Подключить игровые файлы SnowRunner** есть новые кнопки **«Черновики и история загрузки»**, **«Склады: просмотр остатков»**, **«Маршруты»**, **«Схема сохранения»**. В калькуляторе также доступны быстрые кнопки «Черновики» и «Маршруты».

**Именованные черновики:** у каждого игрового профиля отдельные сохранённые планы. Доступны создание, поиск, копирование, переименование, удаление и восстановление. История последних 30 изменённых планов хранится отдельно. Загрузка сохранённого плана не меняет файлы SnowRunner.

**Складская оценка:** определённые из JSON поля `cargoAvailable` **предварительные, схема не подтверждена**. Пользователь вручную сопоставляет внутренние ID грузов с позициями каталога. Затем можно посмотреть предполагаемый дефицит именно на выбранном складе по грузам в текущем калькуляторе. Несопоставленные грузы показывают неизвестные количества. Конфликтующие сопоставления блокируют оценку, склады не суммируются, значения `-1` помечаются как вероятно безлимитные. Это **не** достоверный учёт реальных остатков, и никакое автоматическое списание в игре не выполняется.

**Маршруты:** можно вручную составить последовательность остановок (включая известные ID карт), менять порядок, сохранять маршрут и текущую загрузку в выбранном профиле, возвращать маршрутный состав груза в калькулятор. Реального графа дорог нет; программа **не** вычисляет время пути, длину или проходимость. Точки со статусом посещённых помечаются по выбранному JSON-сохранению, если такие данные в нём есть.

**Диагностика структуры:** просмотр списка безопасных известных имён полей и типов данных без исходных значений, идентификаторов игрока и игровых объектов. Отчёт можно скопировать из окна в буфер обмена. В игровую директорию ничего не записывается.

**Проверено:** 73 автоматических теста на синтетических сохранениях, 6 графических smoke-сценариев на виртуальном Linux-дисплее. **Не проверено:** настоящие сохранения конкретного игрока, реальная установка Steam/Epic, работа оверлея на Windows, Windows EXE и Xbox WGS. Для этих испытаний нужны подходящие реальные данные и Windows-окружение. Windows EXE собирается только на Windows через `build_windows.bat`.

## Быстрый запуск

1. Распакуйте **весь** ZIP-архив в отдельную папку.
2. На Windows установите Python 3.10 или новее с Python Launcher (`py`).
3. Дважды нажмите `run_windows.bat`. Он проверит наличие Pillow и fonttools и при необходимости установит их.
4. Чтобы создать отдельный `.exe`, запустите `build_windows.bat`. Готовый файл появится в папке `dist`.

**Важно:** ZIP содержит полностью собранный исходный проект с запуском для Windows, но не содержит уже скомпилированного EXE. PyInstaller необходимо запускать на Windows. Нативная сборка и работа горячей клавиши над реальной игрой на Windows в этой среде ещё не проверены.

## Исправленный интерфейс

- Одно главное окно без дублирующей белой рамки Windows (используется собственная шапка на Windows). Изменение масштаба не уменьшает весь интерфейс внутри чёрного поля.
- Фон и панели заполняют окно при любом масштабе; размер и положение окна сохраняются между запусками. Сворачивание, разворачивание, перетаскивание шапки и изменение размера за правый нижний угол.
- Исправлены размеры поиска и переключателя языка, выравнивание текста, жёлтые заголовки и переходы между разделами.
- Прокрутка колесом, полоса прокрутки и синхронное выделение строк. Поиск, четыре режима сортировки и переключение языка RU/EN.
- Из карточки груза можно перейти в связанный крафт и вернуться кнопкой «Назад к грузу» или `Alt+←` с сохранением поиска, сортировки и позиции списка.

## Калькулятор грузов

- Поиск материала в левой колонке, прокрутка колесом и перетаскиванием полосы прокрутки.
- Выбор груза и кнопка «Добавить», изменение числа единиц `+` / `−` сразу в правом списке, удаление строки `×`, автоматический подсчёт слотов.
- Независимая прокрутка правого списка загрузки.
- По умолчанию показаны грузы, встречающиеся в извлечённых игровых рецептах. Кнопка «Из рецептов / Все грузы» позволяет открыть расширенный старый каталог, в котором могут быть позиции, требующие дополнительной проверки.

## Крафт и справочник

- 100 записей рецептов из переданного пользователем `initial.cache_block`; реальные названия региона и карты на выбранном языке без технических ID.
- Рецепты с ингредиентами, количеством, результатами, генератором и привязкой к карте. Некоторые производственные площадки открываются только после выполнения игровых задач.
- Понятный ручной редактор рецептов без ввода JSON. Импорт JSON, `initial.cache_block` и поддерживаемых игровых архивов.
- Справочник: поиск, сортировка, выбор, колесо мыши и полоса прокрутки; по умолчанию — материалы из игровых рецептов, полный каталог переключается отдельно.
- Свои PNG/JPG/WebP-иконки для каждого груза и возврат к стандартным иллюстрациям.

### Предпросмотр до сохранения

Изменения видны в **живом предпросмотре справа**, а также в отдельном увеличенном окне **«Открыть предпросмотр в отдельном окне»**. Можно переключить образец между грузами, крафтом и настройками. Цвета, фон, шрифты, размер текста, масштаб и иконки обновляются до сохранения. Кнопка «Отмена» оставляет действующую тему без изменений; «Применить изменения» сохраняет новую конфигурацию.

## Мини-окно крафта поверх SnowRunner

- В разделе **Настройки** нажмите «Показать мини-окно» или откройте его горячей клавишей **Ctrl+Shift+F9**.
- Соседняя кнопка «Клавиша: ...» позволяет назначить своё сочетание с Ctrl, Alt, Shift или Win и буквой/цифрой/F1–F12. При занятом сочетании выдаётся ошибка, а прежняя клавиша сохраняется.
- Горячая клавиша открывает и скрывает одно компактное окно с поиском, списком рецептов, ингредиентами, результатом и названием карты.
- Мини-окно всегда поверх других обычных окон; закрывается через `Esc` или `×`, поддерживает перетаскивание стандартного окна Windows и изменение его размера.
- Предназначено для игры в оконном или безрамочном режиме. **Эксклюзивный полноэкранный режим** игры может скрывать обычные Windows-окна; инъекцию в игру программа не выполняет.

## Пользовательские данные

Настройки, список своих рецептов, темы, загруженные изображения и шрифты находятся в `%USERPROFILE%\SnowRunnerCraftAssistant`. При распаковке новой версии их удалять не нужно. В настройках сохраняются выбранная горячая клавиша и геометрия окна.

## Подключение к установленной игре — первый этап

В «Настройках» появился пункт **«Подключить игровые файлы SnowRunner»**. Открывается окно со статусом локальных источников и кнопками «Обновить», «Папка игры», «Сохранения», «Импорт рецептов».

- Приложение ищет `preload/paks/client/initial.pak` в распространённых Steam/Epic путях и пользовательской папке (включая Steam `libraryfolders.vdf`); папку можно указать вручную.
- Обнаруживаются файлы `CompleteSave.cfg`, `CompleteSave1.cfg` ... `CompleteSave3.cfg` и `.dat` в стандартных Steam/Epic каталогах или в выбранном вручную каталоге.
- Содержимое сохранений читается в **режиме только чтения**, проверяются размер, стабильность файла и JSON-структура. Если формат не поддерживается, приложение отображает ошибку, не пытаясь изменять игру.
- Кнопка импорта использует существующий валидированный парсер крафта для выбранного локального `initial.pak`, если в архиве есть распознаваемые рецепты. Если рецепт не извлечён, текущая база **не перезаписывается**.
- При нескольких найденных установках импорт блокируется до выбора конкретной папки игры. Активный слот не угадывается по временам изменения файлов.

**Пока не реализованы:** непрерывное отслеживание изменений на диске, полноценное извлечение прогресса/гаража/складов из произвольных форматов сохранений, поддержка Xbox WGS, UI переключения игровых профилей и профильное хранение черновиков. Они требуют дальнейшей проверки на реальных сохранениях соответствующих изданий. Эта версия — безопасная основа прямого доступа, а не окончательная синхронизация.

Сборка `.exe` на Windows и тест на реальных установках SnowRunner пока не выполнены. В этом ZIP — исходники с запуском через `run_windows.bat`.

## v16 — игровые профили и автоматическое чтение сохранений (19 ноября 2026)

**Новая версия:** после v15 добавлен модуль `profile_sync.py`, отдельные JSON-файлы профилей и простая синхронизация с изменениями файлов сохранений SnowRunner.

1. Откройте **Настройки → Подключить игровые файлы SnowRunner**. Если игра/сохранения не обнаружены, выберите папку вручную.
2. В списке выберите нужный слот (`CompleteSave.cfg/.dat`, `CompleteSave1...3.cfg/.dat`) и нажмите **Выбрать профиль**. Переключение требует подтверждения. При отказе текущий черновик остаётся открытым.
3. Кнопка **Считать сохранение** выполняет чтение вручную. После выбора профиля приложение каждые **12 секунд** проверяет только его файл на изменения. При обнаружении изменения проверяет стабильность в двух последовательных опросах и заново читает данные. Обновление возможно после фактического сохранения игры на диск.
4. Для каждого игрового слота и для локального черновика сохраняется свой список калькулятора. Перед переключением и выходом черновик записывается в `%USERPROFILE%\SnowRunnerCraftAssistant\profiles\<ключ>.json`. Профильные файлы приложения сохраняются атомарно. Исходные игровые сохранения никогда не записываются и не редактируются.
5. Прямое чтение распознанных JSON-полей: деньги, опыт, время игры, число записей заданий, модели и количество **машин на хранении** (`trucksInWarehouse`), число записей об открытых предметах. Непроверенные поля показываются как неизвестные. Машины на хранении не приравниваются автоматически к грузовикам, физически стоящим в гараже.

**Важные ограничения v16:** формат полноценного хранения грузов на складах, размещение грузовиков по гаражам, корректное завершение конкретных заданий, состояние тумана карты и связывание всех данных с картами ещё не подтверждены на реальных пользовательских сохранениях. Эти значения **не выдумываются и не синхронизируются**. Поддержка Windows Xbox/WGS пока отсутствует. Отслеживание — периодическое считывание файлов, а не прямой доступ к памяти запущенной игры. Изменение времени файла **не используется** для угадывания активного слота: синхронизируется только слот, выбранный самим пользователем.

**Тестирование v16:** 52 автоматических теста (`python -m unittest discover -s tests -p "test_*.py"`) и GUI-сценарий `tests/smoke_profiles_gui.py` на виртуальном дисплее Linux. Проверены независимость двух слотов, сохранение черновиков при переключении, распознавание JSON-полей, отказ от неизвестной/повреждённой структуры, устойчивое чтение, безопасность исходного файла и окно настроек. Реальная Windows-установка и разные версии оригинальных сохранений ещё требуют проверки.

В ZIP находятся **исходники**, запуск `run_windows.bat` и сборка `build_windows.bat`. Скомпилированного `.exe` в архиве нет.

## v17 — прогресс карт, задания и предварительный просмотр складов (19 ноября 2026)

Расширен **read-only** импорт из `CompleteSave*.cfg/.dat`:

1. В `finishedObjs` распознаются ID завершённых заданий; если поле отсутствует, показывается «?», а не ноль. Число записей в `objectiveStates` по-прежнему отдельно считается активными записями, а не автоматически завершёнными заданиями.
2. Из `visitedLevels` выводятся посещённые карты, а из `levelGarageStatuses` — статусы гаражей; значение `2` показывается как открытый гараж. Этот статус **не** означает, что в гараже сейчас стоит машина.
3. Для `cargoAvailable` под объектами/идентификаторами `warehouse_*` добавлен **экспериментальный предварительный просмотр** количеств ресурсов. Эти данные **не верифицированы на конкретной версии игры** и не влияют на калькулятор или черновик. Код `-1` показан как вероятный признак бесконечного запаса, однако трактовка подлежит проверке. Никаких автоматических списаний нет.
4. В окне **Настройки → Подключить игровые файлы SnowRunner** доступна кнопка **«Детали прогресса»** с прокручиваемой сводкой и копированием в буфер обмена. Копируется только сводка, а не оригинальные сохранения.
5. Все ранее созданные пользовательские файлы профилей v16 остаются совместимыми. Обновление игровых сведений не изменяет планы загрузки, а игровые файлы не перезаписываются.

**Как проверить:** укажи папку с сохранениями, вручную выбери игровой профиль, нажми «Считать сохранение», затем «Детали прогресса». Автоматическая проверка изменений выбранного файла по-прежнему выполняется раз в 12 секунд.

**Проверки:** 60 unit-тестов + GUI smoke из `tests/smoke_profiles_gui.py` и `tests/smoke_progress_v17_gui.py` на виртуальном дисплее Linux. Реальные файлы `CompleteSave` этого пользователя пока не предоставлены, проверка на Windows, форматы Xbox WGS, туман, машины физически в гараже и точность складских количеств остаются открытыми задачами.

## v25 — Установщик с выбором папки установки

Для создания установщика Windows запустите `build_installer_windows.bat` после установки Python 3.10+ и Inno Setup 6. Скрипт сначала соберёт EXE, затем `SnowRunnerHelper_Setup_v25.exe` в папке `installer_build`.

Мастер установки **всегда показывает выбор пути**, даже при обновлении приложения. Можно вручную написать папку или нажать «Обзор…». По умолчанию: `%LOCALAPPDATA%\Programs\SnowRunner Helper`; при обновлении предлагается ранее выбранный каталог. Установка выполняется для текущего пользователя и не требует прав администратора при выборе доступной ему папки. Также доступны ярлык в меню «Пуск», дополнительный ярлык на рабочем столе и удаление через «Установленные приложения».

**Безопасность данных:** профиль, личные рецепты и настройки остаются в `%USERPROFILE%\SnowRunnerCraftAssistant`. Удаление/обновление установленных программ их не затрагивает. Не устанавливайте приложение в папки, недоступные для записи текущему пользователю.

На Linux проверить реальный Windows-установщик нельзя; перед выпуском следует проверить установку, обновление, смену каталога и удаление на Windows.
