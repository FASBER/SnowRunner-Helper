SNOWRUNNER HELPER v0.31.12 — ИСПРАВЛЕНИЯ ПО ФОТОАУДИТУ

ГОТОВЫЙ ZIP ДЛЯ SnowRunner Update Manager v0.1.6.
Без PatchKit, установки Git, скриптов сборки архива и ручного клонирования.

ИСПРАВЛЕНО ПО УТВЕРЖДЁННЫМ 14 ФОТОГРАФИЯМ

1. Крафт / Калькулятор / Настройки:
   - весь рабочий контент размещается под строкой игрового профиля;
   - панели выровнены по рабочей области (x=197..1295, y=177..718);
   - координаты кнопок, полей поиска, всплывающих меню и прокрутки
     изменяются вместе с нарисованным интерфейсом;
   - классический UI не преобразуется.
2. Редактор оформления:
   - новый предпросмотр использует утверждённую шапку, панель профиля,
     рабочую область и шесть разделов, а не устаревший макет;
   - учтены настройки цвета, прозрачности, фона, шрифтов, масштаба и иконок;
   - "Главная" и "Гараж" доступны в разделе пользовательских иконок.
3. Главная и Гараж:
   - карточки статистики и быстрые действия вместо пустых полотен;
   - данные профиля берутся только из выбранного сохранения;
   - не найденные показатели честно отображаются как «—».
4. Грузы:
   - одинаково называющиеся рецепты при наличии отличия подписываются
     регионом/местом производства;
   - выбранная пользовательская иконка меню сохраняет цвет без перекраски.
5. Сохранены живой поиск, фильтры, просмотр рецептов, калькулятор,
   пользовательские черновики, веса MapRunner, OTA и AppId установщика.

ОГРАНИЧЕНИЯ:
- Настоящий Windows EXE и полный CI проверяются после загрузки на GitHub.
- Предварительные изображения выполнены реальным Tk Canvas и PIL в
  тестовом окружении, не являются скриншотами Windows пользователя.
- Внешний вид ещё требуется сравнить с эталоном на компьютере пользователя.
- Отсутствующие в сохранении показатели не заменяются вымышленными.

УСТАНОВКА:
1. Выбери этот ZIP в SnowRunner Update Manager v0.1.6.
2. Проверь 0.31.11 → 0.31.12; выставь версию вручную при необходимости.
3. Загрузи исходники; дождись зелёного Validate на GitHub Actions.
4. Только после успешной проверки выпусти релиз.
5. Проверь обновление на Windows, пришли реальные скриншоты.

GitHub не изменяется от скачивания ZIP.
