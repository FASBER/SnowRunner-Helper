SnowRunner Craft Assistant v22 — Expedition UI

NEW VISUAL DESIGN
- A completely reworked header with an illustrated mountain ridge and modern HUD-style typography.
- Dark arctic slate surfaces, distinct card boundaries, updated navigation and yellow active-state highlights.
- A continuous left panel with Settings anchored at the bottom.
- All original five sections remain operational: Cargo, Crafting, Calculator, Guide and Settings.
- Classic interface remains available: Settings -> Classic UI. Switch back via Settings -> New UI.

SAFETY AND SCOPE
- Appearance changes only; game saves are not modified.
- v21 data functions and profile management are retained, but real-game data recognition and Windows EXE have not yet been verified in this Linux build environment.
- Screenshots in PREVIEW_V22_* are captured from the running Tk app with a test environment.

VALIDATION
- 80 automated tests pass on Linux.
- Five real GUI screens captured using Xvfb, plus confirmation that switching to Classic UI works.
- Windows-specific behavior still needs an actual Windows test.
