SnowRunner Helper v0.31.15 — исправление загрузки Steam-сохранений.

Причина: файлы CompleteSave.cfg, CompleteSave1.cfg, CompleteSave2.cfg могут
содержать один завершающий нулевой байт и различающиеся оболочки JSON
(CompleteSave, CompleteSave1, CompleteSave2).
Поддерживаются все три варианта. Файлы игры не изменяются.
Только в памяти выполняется нормализация имени внешней оболочки.
Повреждённые данные и неполная запись по-прежнему отклоняются.

РЕЗУЛЬТАТ ПРОВЕРКИ ТРЁХ ПРИСЛАННЫХ ФАЙЛОВ:
Слот 1: JSON читается, прогресс отсутствует либо минимальный.
Слот 2: JSON читается, прогресс отсутствует либо минимальный.
Слот 3: JSON читается, присутствуют баланс, опыт, задания и техника.
Ни один настоящий файл сохранения НЕ включён в этот ZIP.

Используй готовый ZIP прямо в SnowRunner Update Manager.
Новая версия 0.31.15, текущая в GitHub 0.31.14.
